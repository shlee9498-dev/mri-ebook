# MRI ACADEMY 전자책 — 무료 웹북 (book.mriacademy.gg)

솔로 경쟁전 단독 서바이버(3,712 RP) 실전 개념서의 **무료 공개판**입니다.

## 구조
- **무료 공개**: 서문 + 1~3장 (`index.html`, `intro/ch01/ch02/ch03.html`)
- **유료장(4~7장·부록)**: 이 public 저장소에 **커밋하지 않습니다** → 웹에서 열람 불가.
  전체 내용은 판매용 full PDF에만 포함됩니다.
- `src/`: 무료 챕터 마크다운 원본. 정적 HTML은 다크(#0a0a0c)+골드(#f5c518) 테마로 빌드됩니다.
- 배포: GitHub Pages (main / root) + 커스텀 도메인 `book.mriacademy.gg` (`CNAME`).
